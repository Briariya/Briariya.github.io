Privacy policy

Sestry — last updated 6 October 2026

Sestry is a personal, non-commercial project that runs on a single home computer. It is not offered to the public, and the only Google accounts that use it belong to the project itself.

What data the app accesses

With the account owner's permission, the app uses the YouTube Data API to upload videos to that account's channel, set subtitles, read the account's subscriptions and recent videos of subscribed channels, like videos and subscribe to channels.

How the data is stored

The authorization token and everything the app reads from YouTube are stored only on that home computer. Nothing is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time in the Google account settings, under Third-party apps with account access.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
